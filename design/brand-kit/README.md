# Tip or Skip — working brand kit

Direction A · Split percent · October 16, 2026

Open **Tip-or-Skip-Brand-Overview.png** first. This develops the recommended direction into editable assets for review and implementation. The name remains a working choice; see **Name-Research-Notes.md**. This kit does not change the app or publish a store listing.

## What is included

| Folder | Contents |
| --- | --- |
| `symbol` | Original split-percent symbol, editable SVG and transparent PNG |
| `wordmarks` | Horizontal and stacked wordmarks for light and dark backgrounds, SVG and PNG |
| `app-icons` | Opaque app icon, adaptive layers, monochrome layer, transparent splash image, Play icon |
| `ui-icons` | 11 original 24 × 24 SVG navigation and category icons |
| `components` | Light and dark verdicts, tip button states, Pro tags, paywall headers, empty-state illustrations |
| `tokens` | Color and typography references, CSS variables, calculated contrast checks |
| `fonts` | Original Bricolage Grotesque, Inter, and JetBrains Mono variable TTF files with their OFL licenses |
| `store` | Feature graphic and four clearly marked screenshot templates |
| `previews` | Icon grid, static mask previews, 48 px app icon |

The SVG lettering is outlined so the assets render consistently without installed fonts. Text inside a live app should remain native, selectable/accessibility-aware text; component exports are visual references.
